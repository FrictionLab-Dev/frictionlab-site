Products

Friction Lab is focused on three local-first products: Relay for building software, Wayfinder for navigating your working environment, and Code Atlas for understanding your codebase.

Relay

Friction Lab's flagship product — a local-first autonomous software development platform.

Relay In development

Local-first autonomous software development platform. Relay turns detailed human-defined product goals into structured, supervised autonomous development. It plans work, coordinates coding agents, governs execution, captures evidence, reviews results, and drives missions toward completion — combining probabilistic AI reasoning with deterministic workflow control.

Friction Lab's flagship product. A native macOS control plane for autonomous software development. Not a chatbot. Not just another coding agent.

Navigate

Wayfinder

Find where you want to go and get there.

Wayfinder CLI RC 1 available

Local-first navigation for everything you're working on. Wayfinder helps you find a destination and get there without losing your place. It started as fast filesystem navigation in the terminal, and that capability remains central: the Rust CLI is the part of Wayfinder available today.

Wayfinder is expanding toward a unified local navigation layer across macOS, built around destinations and working contexts rather than generic search. The aim is that asking for "relay" will one day show the project folder, the open windows, the browser tabs, and the saved workspace that belong to it, without choosing a source first.

Available now: the Wayfinder CLI (RC 1). In development: Wayfinder for Alfred and unified contextual search. Planned: window, browser, and workspace support. None of it is part of the current release.

Understand

Code Atlas

A developer knowledge system for the context behind a codebase.

Code Atlas In development

Local-first developer knowledge, built around your codebase. Code Atlas is a Markdown-native workspace for structured project memory — connecting notes, decisions, source references, and architecture context through project-aware navigation and a reusable reference architecture.

Its job is to create, preserve, and structure knowledge, not just to locate it. Captures the context behind a codebase and generates AI-ready context packets. Still in active development and not yet public.
