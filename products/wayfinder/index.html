Wayfinder

Find where you want to go and get there.

Wayfinder is a local-first navigation and retrieval layer for your working environment. It started as a fast terminal navigator, and that Rust CLI is the part of Wayfinder available today. The product is growing beyond the terminal.

Overview

Find a destination. Recover a context. Get there.

Wayfinder is built around one question: where is the thing I'm thinking about?

Your work is spread across folders, projects, windows, tabs, and half-remembered setups. Wayfinder helps you find a destination and get there without losing your place, whichever of those it lives in.

It began with the terminal and the filesystem. The long-term aim is a navigation layer that works across macOS, so you don't have to decide which app holds something before you go looking for it.

Available today

Wayfinder CLI

Keyboard-first navigation of files and folders in the terminal, with shell-integrated cd, open, copy path, and reveal actions. Released as RC 1.

In development

Alfred and unified search

Wayfinder for Alfred, and contextual search that brings several kinds of local destinations into a single set of results. Not part of RC 1.

Planned

Wider destinations

Application and window search, browser tabs, browser history, and bookmarks, plus saved workspaces that restore a working context. Part of the intended direction; none of it is in RC 1.

Being explored

Actions on destinations

Doing something once a destination is found, such as running terminal commands or other local actions. Whether and how this fits is still an open question.

Today

The Wayfinder CLI

The released part of Wayfinder: a lightweight terminal UI for moving through files and folders.

Why

Where it started

The terminal is powerful, but file navigation can still be slower than it should be.

You may know roughly where something is, but still need to cd, ls, tab-complete, jump back, copy a path, or open something elsewhere.

Wayfinder adds a small interactive layer on top of your file system so you can move faster without leaving the keyboard. That capability remains central to the product.

Built with

What it does today

  • Keyboard-first folder browsing.
  • File and folder selection.
  • Open actions.
  • Copy path actions.
  • Print selected paths back to the shell.
  • Shell wrapper integration.
  • Current-directory startup with fallback behavior.
  • A lightweight terminal UI built with Rust.
  • Automated release verification and packaging scripts.
  • Automated test coverage across install, uninstall, and core navigation flows.

Philosophy

Destinations, not search results

Wayfinder is about getting somewhere, not about producing a long list of matches.

Approach

Built for flow

  • A destination is anywhere you want to be: a folder, a project, a window, a tab, or a saved working context.
  • You describe what you're thinking about; where it lives is Wayfinder's problem.
  • Arriving is the goal. The app you land in does the actual work.

Scope

Intentionally small

  • It is not a full file manager.
  • It is not trying to replace Finder.
  • It is not trying to replace your editor.
  • It is not trying to replace your shell.

It exists for one job: help you get to the right place faster.

Surfaces

More than one way in

The CLI is the first interface to Wayfinder, not the only one planned.

Direction

One question, every local context

Search for a project once and see where it lives across your Mac. This is the direction Wayfinder is being built toward, and it is not available in RC 1.

Recover a context

Saved workspaces

Planned: saving a working context as a group of files, projects, application windows, browser tabs, and terminal locations, so you can jump back into a project as you left it.

Being explored: acting on a destination once it's found, including running terminal commands and other local actions.

None of this is released. It is described here so the direction is clear, not because it can be used today.

Principles

Local-first by design

What holds for the CLI today is meant to hold for every surface that follows.

  • It runs on your machine. No account, subscription, or cloud service is needed to navigate.
  • What Wayfinder looks at stays local. Your files, tabs, and history are not something to send elsewhere.
  • Navigation, not management. Wayfinder does not move, rename, delete, or edit your files.
  • The shell and your other tools stay the source of truth. Wayfinder takes you there and steps aside.
